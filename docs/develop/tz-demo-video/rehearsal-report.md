## Что изменено

Сложная правка теперь передаётся точными заменами цитат. При явном уточнении модель выбирает доступное неприменённое предложение текущей редакции; сервер сохраняет остальные подготовленные изменения и повторно проверяет область. Прежний полный раздел больше не переписывается ради небольшой поправки. Q04 уточнён по пунктам, Q09 отдельно задаёт новый UUID при смене файла и ветви двух диаграмм. Один Q04 всё ещё требует просмотра: промежуточный ответ этой репетиции пропустил ветвь гонки в диаграмме и не считается завершённой правкой.

При применении сервер передаёт проверяющему сохранённый авторский запрос, связанный с предложением, и предшествующий контекст. Клиент не может подменить эту просьбу; повреждённая ссылка отклоняется до модели. Проверяющий отличает разрешённую замену формулировки от противоречия между разделами. Для старых предложений без ссылки сохраняется проверка согласованности. Авторизация, CAS и атомарное сохранение остаются на прежнем пути.

В адаптере Ollama включён стандартный управляющий флаг thinking: раньше политика семейства Qwen перезаписывала вложенный think. В отдельном полном корпусе выявлен и исправлен формат числового доказательства V17: значение одно, название и значения в замечании копируются из факта. Корпус и пороги не менялись.

## Блокирующие предпосылки и непроверенные границы

1. Создание БТ выбирает название из действующего справочника. Записи «БТ загрузки заявок CSV — учебное демо» нет. Обычный справочник и существующие документы не изменялись, фиктивное согласование не создавалось. Поэтому M03/M08 не выполнены; доступные несвязанные БТ не использованы вместо нужного основания.
2. У тестового пользователя интерфейс сообщает «EVA: нужен токен». Импорт, первичная привязка, внешнее B/L/R и публикация не выполнялись. Дополнительные реальные страницы не создавались.
3. Нет отдельной проверенной учётной записи читателя в созданном проекте; права других пользователей и глобальные настройки не менялись. Серверный запрет по роли и раздельность черновиков двух пользователей не приняты.
4. M07 не готов к положительной съёмке: широкий запрос и один уточняющий запрос не достигли требуемой полноты. Отрицательная глава также не завершена из-за ложной блокировки Q06. Сценарий содержит условные сцены исправления, но наличие их текста не означает успешной репетиции.
5. Рендеринг PlantUML/Mermaid в конечном документе не проверен. Фактическая визуальная репетиция выполнена в браузерном окружении около 1280×720; подтверждения итогового кадра 1920×1080 нет. Контрольный скриншот показывает настоящее состояние, не макет.
6. Сохранены UI-снимки, прочитанные значения редакторов и отдельные строго ограниченные read-only наблюдения трёх собственных документов в PostgreSQL. Запись БД выполнялась только обычным интерфейсом. Независимые провайдерские ID и параметры каждого upstream-вызова не получены; полный сетевой/модельный evidence packet ещё не собран.
