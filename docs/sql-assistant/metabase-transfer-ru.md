# Полезные решения Metabase: оставшиеся пять задач

Персона: аналитик данных, режим конечного пользователя.
Сценарий: аналитик задаёт вопрос по сохранённому результату, явно выбирает
источники и определения и переходит к проверяемому изменению SQL. Владелец
реализации и проверки — один агент. База: `5637343b4`, общий dirty checkout;
изменения локального расширения SQL-помощника, без изменения общих UI-примитивов.

Приёмка и проверки:

| Задача | Наблюдаемый результат | Проверка |
| --- | --- | --- |
| Контекст вопроса | У ввода видны запуск, версия SQL, параметры и часовой пояс; выбранная строка привязана к этому запуску. Устаревший контекст отвергается до модели | API persistence, UI |
| Определения метрик | Перед новым расчётом показаны совпадения из доступного реестра. Пользователь выбирает определение либо явно продолжает исследование; неоднозначность не разрешается автоматически | Правила поиска, API, UI |
| Карточки | Типизированные данные открывают SQL исходного запуска, сравнение предложения и продолжение исследования. Markdown не исполняет команды | API и UI |
| Упоминания | `@` предлагает доступные таблицы и определения; перед отправкой сервер заново разрешает идентификаторы. Подмена названия, чужой объект и устаревшая версия не используются | API ACL/версии, UI клавиатура |
| Ошибки | Исправимый формат ответа модели получает максимум одну попытку исправления; доступ/инфраструктура завершают операцию. Ввод сохранён, конфликт требует обновления; повтор команды сохраняет идемпотентность | Adapter, API replay, UI |

Потребители: создание исследования, чат выбранного результата, предложение SQL,
существующий реестр определений, каталог OpenMetadata и read-only SQL runtime.
Права tenant/владельца/каталога, сроки хранения, CAS и явное применение/исполнение
SQL сохраняются. Новых таблиц и собственного executor нет.

Проверки модели — только qwen3.8. Контролируемый браузер не доказывает живую
интеграцию с каталогом, worker и LLM. Известный блокер установки базы помощника
описан в `.local/archives/sql-result-review-deploy-20261028/report.json`.

Checkpoint 2026-10-29: все пять направлений реализованы локально. На базе
`5637343b4` (dirty) прошли 117 backend-тестов, 4 соседних worker-сценария,
27 UI-тестов, type-check, ESLint/Ruff, сборка SPA и 11 Chromium-сценариев.
Проверены светлая тема 1440×1000 и тёмная 390×844, в том числе размещение
кнопок внутри панели. Три синтетических сценария с реальным `qwen3.8` прошли;
это не сквозная проверка живого приложения/каталога/worker.

чтения истории на backend проверена отдельно на текущих исходниках: для 50

Pilot: один владелец, без делегирования; scope — UI/API/domain и узкая политика

исправления формата, чтение истории, перенос кнопки и состояние упоминаний.
Конкурентные изменения сохранены; итоговая приёмка локальная, без деплоя.
